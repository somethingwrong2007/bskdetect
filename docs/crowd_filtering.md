# 观众过滤方案

**目标**: 剔除观众席误检，保留场上球员和裁判

**实施日期**: 2026-11-24

---

## 🎯 策略设计

### 核心原则
1. **观众剔除** - 通过多重过滤条件
2. **裁判保留** - 裁判在场上活动，符合球员特征
3. **宁可漏检，不可误检** - 精度优先于召回率

---

## 🔧 五层过滤管道

### Filter 1: 置信度阈值
```python
if p.score < 0.45:
    continue
```
**作用**: 过滤低质量检测（通常是远处观众）  
**阈值选择**: 0.45（平衡点：保留裁判+球员，剔除大部分观众）

---

### Filter 2: 长宽比检查
```python
aspect_ratio = bh / max(bw, 1)
if aspect_ratio < 0.8 or aspect_ratio > 4.5:
    continue
```
**原理**:
- **站姿人员**（球员/裁判）: AR = 1.5-3.5（高瘦）
- **坐姿观众**: AR = 0.5-1.0（矮胖或正方形）
- **极端情况**: AR > 4.5 可能是广告牌误检

**裁判保留**: ✅ 裁判站立姿态与球员相同

---

### Filter 3: 最小尺寸限制
```python
min_height = max(60, rgb.shape[0] * 0.05)  # 5% 帧高
min_width = max(30, rgb.shape[1] * 0.025)  # 2.5% 帧宽
if bh < min_height or bw < min_width:
    continue
```
**作用**: 过滤过小的检测（远处观众、背景人物）

---

### Filter 4: 球场ROI过滤 ⭐ 最关键
```python
if court_bounds is not None:
    cx, cy = (p.bbox[0] + p.bbox[2]) / 2, (p.bbox[1] + p.bbox[3]) / 2
    if not _point_in_rect(cx, cy, court_bounds):
        continue  # Outside court = spectator/bench
```
**原理**: 
- 标定后生成球场边界框
- 只接受球场内的检测
- 自动排除：观众席、替补席、记分台

**裁判保留**: ✅ 裁判在球场内活动

**前提条件**: 必须完成球场标定

---

### Filter 5: 关键点质量检查 🆕
```python
if p.kpts is not None:
    high_conf_kpts = np.sum(p.kpts[:, 2] > 0.5)
    if high_conf_kpts < 4:
        continue  # Likely seated spectator
```
**原理**:
- **站姿人员**（球员/裁判）: 通常有6-12个高置信度关键点
- **坐姿观众**: 
  - 腿部被遮挡 → 髋/膝/踝关键点conf低
  - 非常规姿态 → 整体关键点质量差
  - 通常只有2-4个上半身关键点可见

**阈值选择**: ≥4个高置信度关键点（conf > 0.5）

**裁判保留**: ✅ 裁判正常站立，关键点质量好

## ⚠️ 边界情况处理

### 情况1: 未标定时无法使用Filter 4
**问题**: 没有court_bounds，ROI过滤失效

**缓解措施**:
- Filter 2（长宽比）仍然有效
- Filter 5（关键点质量）能过滤大部分坐姿观众
- 建议：尽快完成标定以启用完整过滤

### 情况2: 裁判站在边线外
**问题**: 裁判可能短暂离开球场边界

**当前行为**: 会被Filter 4过滤掉

**改进方案**（可选）:
```python
# 扩大ROI边界50px作为缓冲
court_bounds_expanded = (
    x_min - 50, y_min - 50,
    x_max + 50, y_max + 50
)
```

### 情况3: 球员坐在替补席
**问题**: 真实球员下场休息时会被过滤

**当前行为**: 正确过滤（我们只需要场上活跃球员）

**如果需要保留**: 降低Filter 5阈值至≥2个关键点

## 🎓 经验教训

### 什么有效
1. **多层过滤管道** - 每层过滤特定类型的假阳性
2. **基于位置的过滤** - ROI是最强的信号
3. **姿态质量检查** - 坐姿vs站姿差异明显

### 什么无效
1. **单纯提高置信度阈值** - 会同时过滤远处的球员
2. **仅依赖尺寸过滤** - 远近摄像机视角差异大
3. **复杂的ML分类器** - 过度工程化，简单规则更有效

### 最佳实践
- **先标定，再检测** - ROI过滤是性价比最高的优化
- **宁严勿松** - 漏检比误检更容易接受
- **可视化验证** - 必须看到叠加层才能调参
